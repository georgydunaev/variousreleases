# variousreleases — Archival Releases, PDFs, and Presentation Bundles

## Overview
`variousreleases` archives compiled PDF releases (`output.pdf`, `output_white.pdf`, `FABLE.pdf`, `CV_EN.pdf`, `CV_DE.pdf`, `CV_RU.pdf`), HTML snapshots (`output.html`, `output_white.html`, `output_html/index.html`), and presentation slides (`antivibecoding.odp`).
